# Channel video template

How "The Stranger You're Robbing" was made, written so the next video can follow the same path.
Everything runs on this laptop with free, local tools. No paid services. No downloads beyond the ones listed.

---

## 1. Channel rules (keep these)

- **Topics:** psychology, motivation and money. Pick things people see every day but ignore, and that hit them inside.
- **Audience:** global. Use `$`, generic brands and places. Never use India-only examples or currency.
- **Facts:** every claim needs a real source (paper, year, journal). List the sources at the bottom of the script. Drop any claim that failed replication, and say "on paper" or "hypothetical" out loud when it applies.
- **Voice:** talks like a human vlogger, to the viewer ("Okay. Quick question."). The screen never reads the sentence back. The screen shows the moment, a reaction, or one pop word.
- **Sound:** voice only. No background music, no sound effects (the user removed them from v1).
- **Length:** the narration decides the length. About 760 words gave 3:40 with Kokoro, not 5:00. Plan about 205 words a minute.

## 2. Look (style guide)

Psych2Go-inspired, but with our own characters. Never copy Psych2Go's leaf mascot.

| Labels | Patrick Hand 46 px `#f4f1ff` |
| Rim glow on characters | silhouette copy offset orange `(16,-12)` + purple `#8f7dff` `(-10,8)` |

**Characters** (built by `rig.js`, see section 5):
- **You / kid:** big round head, hair with a signature curl, mustard hoodie `#e3a63a`, big eyes.
- **Old you:** bald with white side tufts, glasses, teal cardigan `#2f7c72`. Keeps the curl, in white.
- **Stranger:** dark silhouette `#0c1433` with a lavender rim `#b9a6ff`.

**Scene grammar:**
- Cold open: close-up hook, then reveal, then a title card.
- Each part opens with a gradient chapter card: small "part one", big title, character peeking from the bottom corner.
- Inside a part, one main metaphor per line: scanner, jar, buttons, cabinet, chart, phone.
- End card: "Be kind to him."-style closing line + Subscribe button + both characters peeking.

## 4. Step by step

### Step 1: Topic and research
List 5–10 topic ideas. The user picks one. Verify each fact against the original paper.

### Step 2: Script (`SCRIPT-full.md`)
One table per part with two columns, **Voice** and **Screen**. Parts used last time:

0. Cold open (hook question, "me too", the twist, title)
1. The experiment / the core fact
2. Why it matters
3. You already do this (everyday examples)
4. The twist / second study
5. What to do (three moves)
6. Close (emotional, call to action, end card)

Get the user's approval before any build.

### Step 3: Narration lines (`film/script.json`)
One entry per spoken line: `[text, silence-before-seconds, speed]`.

```json
["Okay. Quick question.", 0.3, 1.0],
["So, back in two thousand nine, some researchers at Stanford did something kind of brilliant.", 1.1, 1.0]
```

- Use about 1.1–1.2 s of silence before a new part and 0.3–0.6 s between lines.
- Use speed 0.84–0.92 for emotional lines and 1.0–1.05 for fast asides.
- Spell numbers and odd words the way they should sound: "two thousand nine", "one a.m.", "today you".
- Keep each line to one idea. Scenes sync to line boundaries.

### Step 4: Voice
```bash
.venv-tts/Scripts/python.exe tools/vo-film.py
```
Kokoro voice `af_heart`, 24 kHz. The script trims each line, adds the gaps and normalises the volume.
It writes `film/assets/vo.wav` and `film/assets/vo.json` (start and end of every line).
The user must listen; I can't hear audio. Chatterbox is blocked on this company laptop by Application Control. Do not work around that.

### Step 5: Scene list (`tools/prep-film.cjs`)
Edit the `scenes` array: `[id, file, start]`, where start comes from a line time. `L(i, f)` is the time at fraction `f` of line `i`.

```js
['phook', 'hook', 0],
['reveal', 'reveal', L(3) - 0.05],
['card1', 'card1', L(6) - 0.4],      // card a little before the part's first line
['scan', 'scan', L(6, 0.62)],
```

Each scene runs until the next one starts. Then run:
```bash
node tools/prep-film.cjs            # full film
node tools/prep-film.cjs 51.75      # cut at 51.75 s for a check render
```

### Step 6: Build scenes (`film/compositions/<id>.html`)
Copy an existing scene as a starting point:
- `card1.html` for chapter cards.
- `scan.html` for a character plus props.
- `close.html` for multi-beat scenes.

See section 5 for the rig and the animation syntax.

### Step 7: Check and look
```bash
cd film
npx hyperframes check --json
npx hyperframes snapshot --at 55,62.5,69,...
```
Fix every error. Weigh the warnings: `dead_stretch` means nothing moves for more than 3 s, so add a blink, bob or pop. Open the contact sheets and look for overlaps, stray props and wrong positions.

### Step 8: Render
```bash
npx hyperframes render -o renders/<name>.mp4 --quiet
```
- A 52 s check render takes about 5–10 min. The full 3:40 film takes about 20–40 min. Run it in the background.
- Show the first minute to the user before rendering the whole film.
- To change only the audio of a finished video, swap the track with ffmpeg instead of rendering again (takes seconds):
```bash
ffmpeg -i renders/v1.mp4 -i assets/vo.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest renders/v2.mp4
```
- Files over 30 MB don't reach phone/web. Make a smaller copy if the user needs it there.

## 5. Scene building kit

### Scene file skeleton
```html
<template>
  <style>
    @font-face { font-family: "Hand"; src: url("assets/fonts/PatrickHand-Regular.ttf"); }
    #root { position: absolute; inset: 0; background: #1a2b66; overflow: hidden; }
    #xx-art { position: absolute; inset: 0; }
    .rk { stroke: #0d0f22; stroke-linecap: round; stroke-linejoin: round; }
    .pop { font-family: Hand; font-size: 150px; fill: #ffb35c; stroke: #0d0f22; stroke-width: 14px; paint-order: stroke; stroke-linejoin: round; }
    .lab { font-family: Hand; font-size: 46px; fill: #f4f1ff; }
  </style>
  <div id="root" data-composition-id="xx" data-width="1920" data-height="1080">
    <svg id="xx-art" class="clip" data-start="0" data-duration="30" viewBox="0 0 1920 1080" data-layout-allow-overflow>
      ... art ...
    </svg>
  </div>
  <script>
    Rig.fill();
    const tl = gsap.timeline({ paused: true }), A = s => Rig.at(s, "xx");
    Rig.run(tl, "xx");
    // hand-written acting here, timed with A("line,fraction")
    window.__timelines["xx"] = tl;
  </script>
</template>
```
- Prefix every id with the scene's short name (`xx-`), so ids never clash.
- Give the inner `data-duration` a long value (30+). The host slot in `index.html` decides how long the scene actually shows.

### Characters (`rig.js`)
Put a static transform on an outer group, and the character in an inner group:
```html
<g transform="translate(560,600) scale(0.6)"><g id="xx-kid">
  <g data-rig="kid" data-p="xk" data-o='{"mouth":"smile","brows":"up","look":[30,-4]}'></g>
</g></g>
```
- `data-rig`: `kid`, `old` or `sil`.
- `data-p`: a short unique prefix. Parts get ids like `xk-eyes`, `xk-p1`, `xk-p2`, `xk-bl`, `xk-br`, `xk-m-smile`, `xk-tears`, `xk-sweat`.
- **Kid options:**
  - `mouth`: worry, smile, o, flat, grin, sad
  - `brows`: worry, up, flat, mad
  - `look`: [x, y] pupil offset
  - `dollar`: $ pupils
  - `sweat`, `tears`
  - `happy`: closed happy eyes
- **Old options:**
  - `eyes: "open"` for pupils (default is happy arcs)
  - `mouth`: grin, smile, sad, o, worry
  - `sadbrows`, `tears`, `look`
- Size guide: scale 0.55 is the main character, 0.45 is two-shot, 0.25–0.3 is a small figure in a slot or photo. Local head radius is 290, and the body reaches y = 520.

### Timing on narration: `data-in` / `data-out`
Any element can enter or leave on a point in a voice line. No times are typed in seconds.
```html
<text class="pop" x="960" y="230" text-anchor="middle" data-in="19,0.72,pop" data-out="20,0,pop">charity</text>
```
- Format: `line,fraction,kind`. Fraction 0 is the start of the line and 1 is the end; values below 0 or above 1 are allowed.
- `data-in` kinds: `up` (default), `down`, `left`, `right`, `pop`, `fade`, `shot` (blur in), `grow` (bars, from the bottom), `growx`, `draw` (stroke draw; set `data-len`).
- `data-out` kinds: `fade` (default), `pop`, `shot`.

### Acting helpers (inside the script)
```js
Rig.look(tl, "xk", 30, -6, A("26,0"));          // pupils move
Rig.mouth(tl, "xk", "smile", "grin", A("25,0.5"));
Rig.brows(tl, "xk", "worry", A("12,0.25"));
Rig.squint(tl, "xk", A("14,0.84"), 0.4);        // wince
Rig.widen(tl, "xk", A("10,0.6"));               // surprised pupils
Rig.blinks(tl, "xk", 0, 20);                    // automatic blinks, so faces never freeze
```
- Nods: `tl.to("#xx-kid", { y: 22, duration: 0.18, yoyo: true, repeat: 1 }, t)`.
- Head shake: `rotation` with `svgOrigin: "0 300"` (the neck).
- Shiver: `x` yoyo with many repeats.

## 6. Mistakes already made (don't repeat)

- **GSAP on an SVG element with a `transform` attribute replaces that transform.** Put the position on a static outer `<g transform>` and animate an inner `<g id>`.
- **`fromTo` renders its from-state at build time.** A prop meant to appear later shows from frame 0. For a later reveal, use `tl.set(el, {opacity: 1}, t)`, then a `fromTo` without opacity.
- **Don't combine `data-in="...,draw"` with a `stroke-dasharray` attribute.** A dotted line then shows from the start. Use `fade` for dotted lines.
- **When scaling, put the same `transformOrigin` in both the from and the to.** Changing the origin mid-tween shifts the element.
- **No template literals in `querySelector`.** The HyperFrames bundler crashes on them.
- **Clip paths:** to hide something inside a drawer or slot, give it a `clipPath` the exact size of the opening.
- **Windows Git Bash:** quoted heredocs with HTML and `'` sometimes fail. Write files with the Write tool and make bulk edits with a small node script.
- **PowerShell `Get-Content`/`Set-Content` breaks UTF-8.** Use Bash or node.
- **Helper scripts are `.cjs`,** because `film/package.json` has `"type": "module"`.
- **A smoothing step in Python with `np.convolve` on 10 M samples hangs.** Use a cumsum moving average.
- **Never use a system font through `local()`.** It doesn't survive the render. Always bundle the font file.
